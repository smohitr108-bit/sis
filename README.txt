Default unlock code: shraddha

To publish with GitHub Pages:
1. Upload all three files to the ROOT of the repository (or put them in a separate folder if you want to preserve another existing website).
2. Open Settings > Pages.
3. Choose "Deploy from a branch", branch "main", folder "/(root)", then Save.
4. Wait a few minutes for the published site.

To change the password, edit SECRET_CODE in script.js.
Note: This is a playful front-end lock, not secure authentication. The password is visible in the JavaScript source.
